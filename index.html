先搭骨架再落词块
每题先做这 6 步
找有限谓语。先圈出有时态/情态的动词：is, has, did, will, couldn't, have been。不要一上来按中文顺序拼。
数句子层级。that/who/if/why/before 后面往往另开一个从句；and 可能连接两个并列分句。每一层都要有自己的主语和谓语。
只搭主干。先排 S + V + O/C：I + couldn't finish + it；The print shop + stays + open。暂时不放时间、地点和长修饰语。
锁住紧密组合。动词和代词宾语不能拆：finish it / found it / take the call；固定搭配也整块看：interested in / next to / a lot of。
再挂修饰语。名词后挂定语从句或介词短语；句尾再放地点、时间。长主语必须全部说完，主句谓语才能出现。
倒查干扰项。题干已经给出的主语、宾语或介词不要重复；最后用“谁做什么、对谁/什么、何时何地”倒读一遍。

1. 代词宾语紧跟动词

it / them 是已知信息，英语通常把它紧贴在动词后，再接地点或时间。

finish it | before the deadline
found it | on the portal
return it | to the library

2. 副词卡在正确槽位

be 动词后：I'm currently swamped；助动词与过去分词之间：have never been；地点通常在时间前。

be + currently + complement
have + never + been
online + now

3. 长主语要完整封口

先找到主语中心词，再把它后面的修饰全部括起来；括号结束后，才是主句谓语。

[The print shop next to the library] | stays open
[The café that is next to the towers] | has...

4. 从句与疑问句分开处理

独立疑问句要倒装；名词性从句内部恢复陈述语序。看到 why/if 不要自动倒装。

Where did you buy it?
I know where you bought it.
